任务：按模型配置合法生成规格与默认值、比例和参考图能力，提供显式OpenAI兼容/Seedream/自定义模板，不依模型名称猜测协议。能力配置沿用config_json，不新建供应商执行系统。桌面消费公开目录，AI选择规格，服务器最终校验。

验证：模型配置、合法规格/默认值、价格覆盖、Token分解/预占/返还/未知/幂等测试，隔离数据库和假供应商链路，后台UI交互、类型/架构/生产构建、相关与完整回归。不部署生产、不调用付费接口、不改既有经营配置，不发版。

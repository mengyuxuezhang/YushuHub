# 图片规格与计费配置

图片模型的能力与计费分开维护。先配置模型支持的规格，再配置价格；客户端只从后台声明的范围选择，用户无需操作技术尺寸下拉框。

## 模型目录

新增或编辑图片模型时，在“图片生成规格”中选择 OpenAI 兼容或 Seedream 模板，核对接口尺寸、计费档位、画面比例和默认规格，点击页面“保存配置”一并保存。模型与规格在同一事务写入，不需要另存一次能力。

- 模板只是起点，不保证任意模型支持模板中的所有尺寸。供应商没有可靠能力查询时，按其文档配置。
- 多个接口尺寸可以共用一个计费档位，例如横图与竖图都归入同一档位。
- OpenAI 兼容入口使用 `size` 字段；支持该字段接收分辨率别名的网关可显式配置 1K/2K/4K，不根据模型名字推测。
- 默认规格决定用户未指定时的选择，建议使用常用档位，不默认选择最高价格。
- 高级设置固定默认质量、参考图数量及 Token 用量协议。当前通用 OpenAI 文生图入口不支持参考图；Seedream 参数适配器支持已配置的参考图数量。
- 档位请求可能返回像素尺寸。例如 2K 返回 2048x2048；模板提供对应像素范围，自定义档位可在高级设置维护返回像素范围，超出范围保留任务待核对。
- 原生 Gemini、异步图片任务、任意自定义参数名和通用图片编辑需要对应协议适配器，本配置不把它们自动转为 OpenAI 协议。

## 图片计费

在计费中心选择图片模型后，三种模式互选：

| 模式 | 配置 | 成功结算 |
| --- | --- | --- |
| 按次 | 一行成本与售价 | 一次成功生成一张计一次 |
| 按分辨率 | 模型各可用档位的成本与售价 | 按已校验的生成档位计费 |
| 按 Token | 基础输入、输出价格 | 按上游实际用量计费 |

成本和售价独立；销售人民币价格继续通过所选套餐的积分单价换算，不复制供应商全部收费规则。页面显示积分和单次预占预估。切换模式会重建未保存价格。

Token 模式须先确认供应商返回可靠的 OpenAI 图片用量。支持 input/output 与 prompt/completion 两套明确字段别名，重复字段冲突、合计矛盾、用量缺失均不按零成功结算。高级分项支持文字输入、图片输入和缓存；缓存从对应输入扣除，避免重复计费。未返回对应明细的供应商应使用基础模式或按次、按分辨率计费。

Token 预占使用高级设置中的每类输入与输出上限，成功后退回未使用部分。实际费用超过预占、结果不确定或用量不可靠时保留原请求与预占待核对，不自动重发、不透支余额；不是自动退款。通用人工核销页面尚未提供。

## 升级与历史

配套 Desktop 3.0.97、管理端 1.9.75。建议先升级后台，再使用新版客户端配置新增规格。

升级会将旧图片目录的缺省规格写成显式配置，保留已有配置、端点、其他参数和普通报价。历史参考图附加收费项停用；新方案不再提供“首张参考图免费”或参考图按张附加收费。按 Token 时参考图仍产生正常图片输入 Token。

历史任务与流水保留原价格快照，不按新配置重新扣款。新请求使用稳定请求标识，重复提交复用原任务；失败明确时返还预占，结果未知时查询原任务，不通过换标识重做来处理。

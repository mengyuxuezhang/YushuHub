# 官方客户端授权与文本来源验证切换清单

本清单配套[公共协议](CLIENT_LICENSE_VERIFICATION.md)。适用于独立授权中心、代理直连现有 New API、无二级代理的方案。签名为 New API 的可选响应能力，不增加供货网关、钱包或专用充值协议。

当前状态（2026-11-02）：独立中心采用正式签名根及显式图片验证码登录，New API已启用可选响应签名。管理端1.9.60已按正式标签c459a0a发布官方实例、GitHub Release及唯一ZIP/清单；桌面源码3.0.80产品提交98572262已发布，唯一源码清单和本机构建机版本匹配。Windows代码签名按负责人明确要求跳过，中心与响应Ed25519签名保持。试点后台d4359a6/1.9.60继续接入固定模式；两个真实限额文本请求及JSON/SSE来源校验已通过，本轮发版没有增加付费调用。

历史平台代理主体的独立一级身份使用显式映射保留数据，试点原构建历史和保护资源访问保持。未迁移代理继续明确名单过渡，旧签发入口关闭。真实旧版本测试站已验证全局更新提示及下载，未自动升级下游、创建或推送代理商桌面安装包；不把源码发版写成现有客户端已自动升级。隔离密钥不能替代正式信任根，完整原生交互安装向导与未来项目产物仍按各自交付验收。

## 发布前固定材料

| 检查 | 通过标准 |
| --- | --- |
| 配套源码 | 记录中心、New API、管理端、客户端四个提交及镜像/构建 SHA-256，不使用浮动标签 |
| 中心信任根 | 核对正式中心 HTTPS 地址、Ed25519 公钥及 kid；固定在官方客户端构建中，不接受品牌或代理配置覆盖 |
| 响应签名 | 独立私钥仅挂载给官方 New API；中心只配置对应公钥；代理只能配置自己的普通 API Key |
| 时间 | 分别核对中心、New API、客户端的独立NTP同步状态，建议偏差小于5秒；不能假设开发机时间正确并据相对差值调整正常服务器。超过允许的30秒前向偏差会拒绝，不能扩大校验窗口掩盖时钟问题 |
| 原部署备份 | 保存各服务原镜像/源码、配置、密钥身份、中心和经营数据库及当前更新清单；备份置于受控环境 |
| 代理身份 | 域名唯一、授权已激活、固定/自定义模式及期限正确；已用额度和用户权益核对一致 |
| 原能力 | 文本、图片、语音、搜索、支付、构建、资源和更新沿原业务路径验证；不能用来源签名测试代替全业务回归 |

## 切换顺序

1. 部署兼容的授权中心，加载正式响应公钥。使用单独试点授权验证激活、停启、续期、到期、绑定及客户端策略；已有授权身份及凭据派生材料保持；中心签名根变更需明确轮换、公钥部署和已激活实例刷新步骤。
2. 部署兼容 New API，配置独立响应私钥。先验证普通无挑战请求不变，再用虚构或明确批准的测试账号验证带挑战的 JSON/SSE、非法挑战在上游前拒绝、重启后签名有效；不依赖新充值接口。
3. 升级试点管理端，验证挑战头透传、固定文本运行时地址约束、终端积分和现有支付不变，图片/语音/搜索配置不被覆盖。旧第三方 Key 不自动当作 New API Key。
4. 从经过审核的客户端源码构建正式试点产物，核对中心信任根、品牌域名、项目与安装身份、运行时和更新签名；不得包含隔离测试入口、测试信任替换或受控配置文件。按桌面仓库发布手册完成安装和升级验收。
5. 用试点账号验证：正常固定文本、后台伪造响应拒绝、首事件缺签返回403、后段篡改中断、停用/到期拒绝新经营而保留登录和历史、自定义模式可用。检查实际用户界面错误及账单；上游成本只以 New API 账单为准。
6. 确认试点后，再经负责人批准扩大范围和发布更新。记录切换时间、提交、产物摘要、操作人及回退版本。

新旧客户端可并存：旧客户端不发送挑战，维持原请求格式；新固定模式客户端需要中心和 New API 的兼容能力。流式首事件验证通过后继续增量交付，不缓存完整答案；后续验签失败不能伪装成功或自动改用其他供应商。

## 故障时回退

| 情况 | 处理 |
| --- | --- |
| 客户端尚未发布 | 回退服务至原兼容版本，保留新配置和证据；不覆盖新增订单、积分或授权变更 |
| 新客户端已使用 | 中心和 New API 至少保留本协议能力，优先回退至已经验收的兼容镜像；不能回退到无签名的 New API |
| 管理端异常 | 回退到支持挑战透传和新授权的兼容版本，保留数据库、加密密钥、用户身份、订单及流水 |
| 签名不匹配 | 检查 kid、公私钥配对、加载版本及系统时间；修复并重启对应服务，不能关闭验签或让代理提供公钥 |
| 响应私钥疑似泄露 | 发布新响应公钥和签名私钥，按影响处置旧公钥；中心策略最长存在24小时缓存，不宣称旧公钥可瞬时全网消失 |
| 中心短时故障 | 沿用尚未到期的签名宽限；已明确拒绝的实例不能恢复旧缓存，禁止手工拼接授权 |
| 已发生业务写入 | 不恢复旧数据库快照覆盖新增流水；按现有数据修复或回退兼容程序 |

回退完成后重新验证登录、中心授权、固定文本签名、普通旧客户端调用、用户权益和关键经营接口，并留存可追溯记录。

## 已有隔离验收及其边界

2026-11-02，独立数据库/端口/测试签名密钥中验证中心、管理端、实际 New API 镜像与模拟供应商，覆盖 JSON/SSE、数据库地址改动、伪造响应、停用/到期、60秒同步、断网与重启缓存规则。完整源码构建的 Electron 产品通过真实登录、生产 preload/IPC、Rust 运行时、固定及自定义模式聊天；未执行正式签名安装包发布或真实付费渠道验收。

联调暴露并修复：中心 iat/exp 使用同一时间快照，避免24小时多出毫秒；客户端先验证流式首事件，再向运行时提交成功状态，首事件无有效签名时返回403。验证保留严格时间检查，隔离客户端测试进程显式对齐测试服务器时钟；上线环境仍须独立通过时间同步门槛。

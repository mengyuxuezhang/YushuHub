# 私有音色供货接入实施合同

此文记录正在实施的设计，不代表接口已经开放。实际进度仍以[总进度](AUTHORIZATION_SUPPLY_STATUS.md)为准。没有存量下游私有音色，不做旧音色迁移；新功能必须覆盖录音上传、训练/试听、首次正式启用、合成、删除、原任务查询和异常清理。

## 归属与服务边界

- 官方音色及供应商密钥留在官方网关；自接音色留在一级自己的服务。授权中心只签发用途和主体范围，不接收录音、试听文本或音频。
- 使用 `rootId + organizationId + subjectHash + modelId` 标识归属。subjectHash来自已认证终端的服务端签名凭据，不来自请求体。用户只见本系统不透明音色ID，不见其他音色、供应商私有ID或账号凭据。
- 音色绑定原模型、账号/连接摘要及原Key身份。Key轮换或连接变化不能静默借用别的账号；删除Key及模型前必须检查新供货音色和未结任务，不能只检查旧ai_private_voices。
- 单用户最多20个未清理音色（含上传、训练、启用、未知状态），同一用户并发创建必须原子占用。录音和音频文件放在受控目录，无公开静态URL；下载须核对相同主体及原任务。

## 原客户端兼容与文件传输

保留现有 `/api/client/voices`、train/activate/synthesize/delete、tasks及鉴权音频/试听入口。公共音色保持现有链路；私有音色不回落旧积分账本。

录音使用有鉴权的multipart上传，仍支持10秒至5分钟的MP3/M4A/WAV、最大20MB。不能把20MB录音转换成base64塞入512KB网关JSON入口，也不能为此放开所有JSON接口限制。一级到官方使用独立、主体及模型绑定的上传接口；供应商收到文件之前，服务端校验格式/时长。文件只使用服务器生成的ID命名，不使用用户文件名拼路径。

## 计量与账务

所有付费动作复用当前用户积分、二级供货及官方一级余额的预占/结算流程，不新建第二套扣款源。价格审核须显式包含试听字符、首次资源启用、启用时实际合成字符及日常合成字符；删除/读取不收费。

供应商音色复刻试听返回实际usage_characters时才据此结算；不可把预估文字长度当实际供应商用量。首次正式合成会伴随启用动作，必须锁定该资源，避免两个启用请求重复收取一次性费用。计费上界、整条价格快照及会员/倍率沿用现有供货约束。

## 持久状态与恢复

资源、操作及文件索引使用独立SQL记录，显式迁移创建；正常启动不执行DDL。作用范围、创建输入摘要和原操作引用不可变，状态变更须锁行并检查合法转换。

上传重试按组织/主体/原请求编号及文件摘要幂等。供应商调用前保存原账号、生成的私有ID和操作阶段；供应商成功后先持久化实际用量及结果，再交给原账本结算。崩溃重启通过原操作查结果；缺少持久证明、结果未知或供应商缺实际用量时保留预占，不重新训练/启用，也不以“查询不到”自动证明没有费用。

录音文件和供应商临时文件分别跟踪清理状态。删除资源必须等待并发付费动作完成或先核对；删除响应丢失时通过原账号权威查询确认是否已删，不能换账号查。已知结果和原账本恢复幂等，未知费用走有凭证的对账。

## 验收门槛

至少覆盖组织/主体隔离、请求体伪造、同模型不同账号、重复上传/激活、20个并发上限、实际试听用量、三层扣费、原价快照、断网/重启/缺用量、文件清理、Key/模型删除保护及原公共语音回归。默认模拟供应商；真实训练另外需要获授权录音和已经完成供应商认证的测试账号。

协议核对来源（2026-10-30）：[MiniMax音色复刻接口](https://platform.minimax.cn/docs/api-reference/voice-cloning-clone)、[复刻流程](https://platform.minimax.cn/docs/guides/speech-voice-clone)、[接口条件](https://platform.minimax.cn/docs/faq/about-apis)。供应商规格和计价按受控配置审核，不硬编码供应商报价。目录索引说明复刻音色未在7天内正式调用会删除；本地有效期不能扩大供应商实际保留期。

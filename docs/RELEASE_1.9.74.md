# 管理后台 1.9.74

Doubao Seedream及关联图片服务商、计费配置不再作为系统内置记录保护，管理员可按普通配置停用、删除。初始化只维护原有音频内置配置，停止自动创建图片模型及其价格，也不再覆盖已有图片配置或恢复已删除的图片模型。

## 升级说明

升级保留现有模型、Key、报价、授权和结算记录，不自动删除数据。历史Seedream记录保持原ID，按原组织归属管理；已有未完成或结果未知的任务时仍阻止删除，处理完成后可走模型归档流程，历史任务和账务保留。普通计费方案须先停用，有结算引用的方案不直接物理删除。音频内置及中心托管配置继续按现有规则保护。

Seedream参数适配继续可用，可按普通图片模型手动配置。本次仅管理端变更，无需升级桌面端；也不自动升级下游站点。

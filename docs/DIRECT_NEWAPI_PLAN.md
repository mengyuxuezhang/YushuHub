# 独立授权与直连 New API

2026-11-01确认。本文件是本分支实施目标，替代旧供货重构方案；旧成果保留在`feat/independent-license-center`，不整体合并，归档源码、数据和证据保留；旧TEST运行服务已按负责人后续决定停用。

## 固定决策

- 从`origin/master`（本次基线2aab87d）开发`feat/license-center-direct-newapi`。
- 永久取消二级代理，无二级数据迁移、上下级授权、分配额度或供货结算。保留一级自己的员工、岗位和组织隔离。
- 套餐按负责人最新要求直接编辑保存并同步关联授权，不提供运营版本选择；未使用套餐可删除，使用中需先更换关联。代理列表提供停用/启用及删除（撤销访问、保留经营数据），审计用中文展示。
- 独立授权中心管理套餐、能力、期限、部署绑定、一次性激活码、Ed25519凭证、续期、暂停、撤销、MFA与审计。功能套餐和固定/自定义模式分别建模。
- 固定模式的文本只走`https://api.okpa.cn/v1`，代理配置自己的Key、模型和售价。服务端执行、测试、导入、配置都不能绕过官方地址；拒绝任意端点和重定向。
- 自定义模式保留主线服务商能力。音频、生图和独立搜索保持原配置与调用方式，不受文本固定地址影响。
- 所有代理都是独立主体，自行向对应上游充值；终端用户仍向本后台付费并消费积分。无供货钱包、模型网关、分润、New API专用结算协议或新现金退款账本。
- 复用主线支付，选择移植旧分支独立的支付请求安全修正。用户积分不换算为上游余额，不输出未核实的上游利润。
- 完整源码交付不能承诺不可修改；官方版本软件限制与许可共同约束，官方构建与资源服务由中心鉴权控制。

## 实施与验收

1. 独立中心及接入：单层授权全生命周期、60秒同步、最长24小时且不超过期限的网络宽限、明确拒绝立即失效；原构建中心不再签发。
2. 删除二级业务接口/菜单/能力与继承逻辑；检测到意外二级数据即阻止升级，不删除或转换数据。
3. 固定文本策略和本组织Key：原第三方Key不自动复制给New API；固定切换提供预览，不覆写非文本配置；保留模型定价和既有调用协议。
4. 用户、订单、积分、会员、项目、密钥及已用额度保持；显式legacy升级后再激活中心，新安装缺中心授权不能默认全权限。
5. 后台check、支付/会员/积分/模型/组织/官方资源专项；前端类型/测试/架构/构建并提交产物；独立MySQL验证升级连续性和两类授权。默认模拟供应商。

当前开发结果见[进度](DIRECT_NEWAPI_STATUS.md)。生产切换、经营数据迁入、正式更新源及付费调用另行确认。测试实例使用独立数据与端口，旧方案连续观察已随经批准的TEST停用结束，不计为七天验收通过。

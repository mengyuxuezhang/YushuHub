# 管理后台 1.9.73

图片模型现在提供独立模型目录、可编辑的相对生图端点和幂等任务接口，供配套客户端基础生图技能使用。服务商Base URL、Key池、图片模型及计费方案继续在后台配置；市场技能只分发创作规范，不承载凭据或扣费逻辑。

每次生成使用稳定请求标识，后台推导用量并锁定价格快照，成功结算、明确失败返还预占，结果未知保留任务供核对。相同请求不会重复创建收费任务。新实例人民币结算无需额外配置人民币汇率；外币仍须配置汇率。

## 升级要求与范围

配套客户端为3.0.95。新客户端需要本次图片任务API；旧图片生成接口保留兼容。配置图片能力及启用的价格方案后才可生成，本次升级不会自动替换既有供应商、Key、模型、报价或发布市场技能。

通用OpenAI兼容JSON接口首批为单张文生图，按实际PNG/JPEG保存；Seedream保留已有参考图字段。Gemini原生、通用图片编辑、异步协议和任意厂商参数不在本批范围。未知结果的供应商自动查询和人工核销页面尚未提供，不应将未知任务当作已退款。

独立授权测试中GPT Image 2和豆包Seedream真实出图、成果保存及唯一消费流水通过；Flux Kontext Max被上游明确拒绝，预占已返还，具体原因仍待排查，不宣称所有兼容模型均已验收。测试报价不代表供应商实际货币费用。

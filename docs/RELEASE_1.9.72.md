# 管理后台 1.9.72

会员卡新增积分单价展示：每张卡按自身售价与赠送积分计算「1 积分 = 多少元」，逐套餐独立，售价或积分缺失时明确提示不可用，不再给出会误导的单价。

计费中心编辑计费方案时，每个计费项新增套餐选择、厂商成本（人民币）与销售价格（人民币）。积分由服务端按所选套餐积分单价自动换算，前端只做预览、不可手填；换算结果四舍五入保留 6 位小数，并作为 `sale_points` 供桌面端扣费。未选择套餐、套餐已停用或套餐未设置价格时禁止保存。

套餐单价在保存时写入 `metadata_json.membershipSnapshot` 快照；后续修改会员卡售价不会追溯影响已保存方案，编辑方案时若检测到单价变化会提示重新确认。会员卡归属仍按创建账号隔离，计费方案仍按组织隔离。

## 升级说明

本版本复用 `ai_model_pricing_components.sale_points` 与 `metadata_json`，没有新增业务表或结构迁移，现有会员卡、计费方案、积分流水按原升级流程保留。升级后需要人工操作一次：打开计费中心逐个编辑既有方案并选择套餐、填写销售价格后保存，旧方案不会自动补算积分单价。

# 宝塔全新部署（候选）

面向代理的[离线 HTML 简版](BAOTA_FRESH_INSTALL.html)。已有实例迁移是独立进阶路线，见[旧迁移手册](BAOTA_DOCKER.md)，当前首发工作已切换为全新部署，旧迁移验证不再是首发门槛。

当前候选版本 `1.9.69-baota.1`。发布维护者从固定源码构建镜像，使用 `packaging/container/render-fresh-compose.mjs` 将批准的 digest 写入 `compose.fresh.yaml`，代理只填写安装口令及可选回环端口，不在目标主机编译 npm。没有已批准生产镜像、公钥或正式发行授权前，候选只用于隔离验收。

实际路径：Docker→容器编排创建/导入预制 YAML → 固定项目名并设置专用安装口令 → 启动 → 宝塔原宿主网站配置域名、反代与 SSL → HTTPS 页面设置管理员 → 登录并按原规则粘贴中心授权接入信息。安装成功不等于授权生效。若面板不提供变量输入框，可使用发行方已填固定镜像的 YAML，仅编辑口令那一行。

专用 MySQL 8.4 LTS 不发布任何数据库端口，数据库只连接内部网络；业务另接出站网络以访问合法中心及供应商。业务映射 `127.0.0.1:7077`，适配宿主 Nginx；不适配直接套用 bridge Nginx 的 `127.0.0.1`。prepare 只准备本项目卷及随机数据库凭据，无 Docker socket。业务 UID1000，只读根文件系统，data/logs/published 及数据库和凭据卷持久化。

首次管理员口令只以现有 PBKDF2 哈希持久保存，完成状态原子保存；重复启动不重置，未完成状态绑定首次域名与密码。已有业务库或不匹配初始化记录拒绝作为空库接管。`/healthz` 表示服务存活（含等待初始化），`/readyz` 仅在业务初始化完成且数据库可读时成功；两者均不表示授权有效。

后续独立宿主升级服务的新装登记适配仍属开发中的交付内容。此阶段候选不宣称已完成后台受控升级；当前没有升级服务时界面应明确提示未绑定。不要用面板改 latest、删卷或重建项目代替升级/恢复。原 root PM2 长链登记不作为新手新装步骤。

2026-11-09：开发已完成隔离正常初始化、登录、缺授权经营禁止及重建持久性试验，仍待独立功能 QA；宝塔具体面板版本和 UI 导入未实装验证。参考[宝塔官方容器编排教程](https://www.bt.cn/bbs/thread-140412-1-1.html)、[11.0.0 文件创建编排说明](https://docs.bt.cn/update-log/linux-panel-11-0-0)、[官方反代指南](https://docs.bt.cn/user-guide/site/php/site-config/reverse-proxy)。不对截图服务器进行操作。

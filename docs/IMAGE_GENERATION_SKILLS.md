# 图片接口与技能规范

## 后台配置

1. 模型服务→服务商：设置供应商HTTPS Base URL，例如`https://provider.example/v1`。
2. Key池：保存此服务商的Key，并选择适用模型；Key仅留在后台。
3. 模型目录：新建图片模型，填写上游模型ID、展示名和生图端点。端点默认为`/images/generations`，最终请求地址由Base URL与该相对路径组成；自定义路径仍须使用OpenAI兼容JSON文生图协议。
4. 计费中心：为该图片能力配置启用的计费方案，支持原有按张/分辨率及请求计量。未配置对应尺寸价格时不能提交，不以缺少价格代表免费。人民币作为结算基准币种固定按1计算，新实例无需另建人民币汇率；外币成本仍须配置对应汇率。
5. 沿用现有模型授权，客户端仅能看到账号可用模型。目录返回独立模型记录ID，区分不同供应商的同名模型；向供应商发送其实际模型ID。

首批每次一张，通用模型使用明确像素尺寸；Seedream保留其档位、水印和参考图字段。其他模型不透传这些厂商专属字段。通用接口以实际返回的PNG/JPEG保存，格式选择属于偏好；Gemini原生、异步任务和通用参考图编辑不属于本批支持范围，不能仅修改技能声明支持。

## 基础技能与市场规范

客户端随包提供`agent-image-generation`基础技能及执行器。后台的技能市场可发布独立命名的海报、电商等创作规范包，沿用当前上传ZIP、发布版本、分配项目及客户端安装/更新流程，不强制自动安装。

规范包只定义提示词、构图和设计要求，并引用当前环境可用的基础技能。不要打包供应商Key、后台Token、固定脚本绝对路径、接口认证或计费脚本。换用同一兼容协议的供应商通常调整后台模型配置即可；新协议仍需后端适配。

## 图片任务与积分

新增已认证接口：`GET /api/client/images/models`、`POST /api/client/images/tasks`、`GET /api/client/images/tasks/:id`及`GET /api/client/images/tasks/by-request/:requestId`。提交字段为`requestId`、目录中的`model`记录ID、`prompt`及可选`size/outputFormat/watermark/referenceImages`；不接受客户端价格或供应商凭据。

服务端推导预占用量并锁定价格快照，复用既有模型任务及积分仓库。相同用户的稳定requestId只执行一次；不同输入复用ID拒绝。成功后结算有效输出，明确失败返还预占；网络断流、超时或无法确认结果保留`outcome_unknown`待核对，不自动重试或直接退款。供应商未给尺寸时沿用请求规格。查询只返回当前用户及组织的任务。既有`/api/client/images/generate`继续供旧客户端使用。

源码更新不自动部署或修改现有供应商、Key和价格。新版客户端需配套本次后台接口；旧后台明确不可用，不静默退回缺少幂等保障的旧生成入口。

当前结果未知的任务保留预占，未实现按供应商查询结果或自动核销，也未新增人工核销管理页面；运营核对流程是后续完善项，不能将未知任务宣称为已退款。生图之外的对话模型正常计费保持原有规则。

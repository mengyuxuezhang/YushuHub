# 管理后台 1.9.64

精简构建状态查询与受理响应，避免反复传输内嵌品牌图片。项目和构建列表先读取本地数据，中央状态在后台同步；页面刷新与定时同步共享进行中的请求，减少加载等待和超时。

完整品牌图片保留给实际打包。轻量响应不覆盖本地完整品牌，历史元数据缺失仍可补齐；状态、错误、日志、产物和摘要保持。旧请求默认完整响应，新版管理端显式请求轻量视图。先升级官方构建中心，再升级代理管理端，两侧都升级后才能获得完整优化。

发版验证包括后端与前端回归、类型/架构/构建、分发与入口烟测，以及大图片响应、原素材保留、旧接口兼容、后台非阻塞和同步合并。只读对照中，约5.94MB的历史状态记录精简至约117KB，减少98%。本版本不涉及桌面端发版或安装包重建，也不宣称解决Rust编译进程非法指令退出。

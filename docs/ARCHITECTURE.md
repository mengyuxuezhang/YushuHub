# 架构与接入边界

羽枢提供 Web 管理界面与 HTTP API。Vue 管理界面位于 `web-admin/src`，Express 启动入口位于 `cloud/ai-admin/server.mjs`，数据库结构和兼容迁移由 `src/db` 管理。

## 领域分工

- `src/routes` 处理 HTTP 输入、身份及权限检查、响应。
- `src/services` 处理模型代理、积分与权益、组织权限、能力市场、品牌及构建等业务。
- `src/repositories` 封装领域数据访问；现有代码逐步按领域拆分。
- 管理界面按领域组织页面、API、状态与组件；旧版 `web/js/admin.js` 只保留兼容入口。

## 第三方应用接入

客户端接口位于 `src/routes/client-api.mjs` 及相邻领域路由。接入方需要实现登录与凭据持久化、模型调用、权益与积分展示、错误处理，以及实际使用的资源市场或客户端策略协议。以路由实现和相关测试为当前接口合同，管理端并非任意 Agent 框架的即插即用插件。

模型请求通过管理端选择服务商与可用凭据，并执行计量与账务处理；终端应用不应获得平台供应商密钥。用户自定义模型是否经过平台计费，以实际接入协议为准。

智能体、Skills 和 MCP 市场负责配置与资源分发；执行由接入方运行时负责。AI 项目现有构建链路适配 Agent Desktop，其他产品需替换品牌、版本和产物适配。部署管理端不授予桌面端或中央构建服务的使用权。

## 数据与权限

组织主体、后台成员、岗位角色、权限和数据范围分开管理。API 扩展需维持跨组织隔离、账务一致性及历史兼容。数据库、上传资源和环境配置属于部署方持久化数据，不纳入源码。

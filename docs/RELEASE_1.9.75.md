# 1.9.75 图片模型规格与通用计费

图片模型可以独立配置生成规格、默认值、画面比例、固定质量和参考图能力。提供模板与高级选项，规格随模型一次保存；普通模型编辑保留已有能力配置。

图片计费简化为按次、按分辨率或按 Token，成本和售价独立。Token 支持基础输入/输出及可选文字、图片、缓存分项；预占后按实际用量结算，缺失或矛盾用量、超预占费用保留待核对，不自动重复出图或透支。

停止参考图按张附加收费，移除首张免费特例。历史流水与任务价格快照保持。升级会为旧图片目录物化已有默认规格，不覆盖显式配置；历史参考图附加组件停用。

配套客户端为 Desktop 3.0.97，建议先升级后台，再使用新版客户端配置新增规格。支持范围与操作步骤见[图片配置说明](IMAGE_MODEL_SPECS.md)。不自动适配 Gemini 原生、任意参数名或异步图片协议。

验证：后端检查236、图片专项68、前端31文件140项、类型/架构/生产构建、分发及前端/导入冒烟通过。隔离环境验证了实际API、账务幂等、三种模式、异常保留与退款，以及配套客户端真实图片下载解码。未知任务的通用人工核销页面尚未提供。

正式交付以不可变标签和官方更新清单为准；下游升级及桌面安装包构建另行执行。

# YushuHub 1.9.99

模型目录新增客户端默认模型和客户端排序。每个组织可指定一个默认文本模型，桌面端在没有可用选择时采用该默认值。排序可跨服务商设置，数值越小越靠前，留空的模型按原有顺序排列在后面。

# YushuHub 1.9.76

- 插件市场支持发布版本、维护头像与介绍、设置项目授权。中央可向具备资源分发权限的下游发布官方插件。下游支持自动同步和手动同步，也可按项目调整可用插件。
- 首批官方插件为 GitHub、飞书、企业微信和钉钉。各插件包含能力介绍、安装与授权说明，以及六条可用于聊天的示例。
- OpenAI 兼容图片模型可独立设置编辑端点与参考图上限。启用后，图片技能会将参考图以 multipart 文件发送到编辑端点，沿用现有图片任务与积分结算流程。

桌面端 3.0.98 增加插件市场、示例跳转及参考图编辑入口。下游管理端升级至 1.9.76 后可接收官方插件。插件调用仍需按使用指引完成本机 CLI 安装与账号授权。已有仅支持文生图的模型需要由运营人员填写有效编辑端点和参考图上限后才能接收参考图。

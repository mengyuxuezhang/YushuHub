# YushuHub 1.9.80

积分流水新增客户端来源列和筛选。新版客户端的模型消费可区分桌面客户端和安卓 App，后台调账单独标记。未记录来源的历史消费显示「来源未记录」。通过手机接续桌面会话时，消费来源按实际运行模型的桌面客户端记录。

升级时自动为积分流水、模型任务和语音任务添加来源字段。客户端与原有后台兼容，来源列需要后台升级后才能查看。

发版前已验证构建产物、后台筛选、模型调用请求来源和异步任务结算。隔离 MySQL 实例验证了四种来源和筛选后的扣费汇总。
